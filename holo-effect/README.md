# Holo Foil — 手刻全息閃卡材質

Bay (3x3) Studio ／ 2026-09-06

---

## 這是什麼

三種可以貼在任何圖片上的「閃卡」效果，滑鼠移過去會跟著轉、跟著閃。

| 材質 | `data-foil` | 長相 |
|---|---|---|
| **方閃** | `grid` | 日系復古方格全息貼紙。每格切成十字四等分：**右上／左下**是放射 CD，**左上／右下**是普通的銀色金屬反光，對角交錯 |
| **碎閃** | `glitter` | 散落的 ✦ 星星，大大小小自然分佈的幻彩。四層遠近各有自己的位移速度，滑鼠一動就錯開，有真的景深 |
| **經典彩虹** | `rainbow` | 斜向彩虹帶 + 細掃描線 + 光柱，寶可夢閃卡那味 |

---

## 怎麼玩

雙擊 **`啟動.bat`** 就開了（或直接雙擊 `index.html` 也行）。

右邊面板由上到下：**材質**（方閃／碎閃／經典彩虹）→ **載體**（A 方形貼紙／B 塔羅牌／C 寶可夢卡）→ **圖片**（底圖／上層圖，按「選擇圖片」上傳，也可以直接把圖拖到卡片上）→ **畫質** → 材質參數 → **輸出 PNG**。

介面是像素／復古視窗風：格線紙底、米色面板、深咖啡粗邊、彩色標題列。圖示全部是自畫的 SVG，沒有用 emoji。

調到滿意 → 按「複製 CSS」→ 貼到你自己的專案。

## 怎麼用在別的地方

複製 `holo.css` 和 `holo.js` 兩個檔，然後：

```html
<link rel="stylesheet" href="holo.css">

<div class="foil" data-foil="grid" data-tilt="14">
  <div class="foil__tilt">
    <div class="foil__art"><img src="底圖.png" alt=""></div>
    <div class="foil__sheen"></div>
    <div class="foil__gloss"></div>
    <div class="foil__over"><img src="上層透明圖.png" alt=""></div>
  </div>
</div>

<script src="holo.js"></script>
```

就這樣。`holo.js` 會自己找到頁面上所有 `.foil` 接上去，不用寫任何初始化。
連 `holo.js` 都不放也能跑，只是變成單純的 hover 效果，不會跟著滑鼠。

**兩個放圖的位置**：

- `.foil__art`（底層）—— 閃光蓋在圖上面。一般的閃卡就用這個
- `.foil__over`（最上層，**選用**）—— 圖蓋在閃光上面，**透明的地方會透出閃光**。
  想做「線稿／框線在最上層、閃光從鏤空處透出來」就放這裡。不需要的話整個 div 拿掉

### 三種載體：`data-carrier`

| 值 | 是什麼 | 比例 | 特徵 |
|---|---|---|---|
| `a` | **正方形貼紙**（預設）| 1:1 | 薄片，幾乎沒有厚度。圖滿版，沒有任何框線文字 |
| `b` | **塔羅牌** | 3:5 | 圓角，側面看得到紙的厚度。圖滿版，沒有任何框線文字 |
| `c` | **寶可夢卡** | 0.716 | 有版型：上方名稱列、中間卡圖框（圖自動裁切）、下方說明欄 |

比例、圓角、厚度全部由 `data-carrier` 決定，不用自己算。

厚度是用 `box-shadow` 堆出來的側邊，偏移量**完全由傾斜決定**：
卡片正對著你時看不到側面（跟真的卡片一樣），轉開才會露出厚度，而且是露在轉開的那一側。

> ⚠️ **卡緣的 box-shadow 絕對不能加固定的向下偏移。**
> 加了的話，卡片完全沒傾斜時下緣還是會硬生生多一條淺色橫帶，看起來像遮罩歪掉。
> （第一版就是這樣，`+1px` 到 `+5px` 那組固定值全部拿掉了。）
C 的版型（名稱列／卡圖框／說明欄）不在 `holo.css` 裡 —— 那是調參台自己的東西，
`holo.css` 只管比例圓角厚度，版型你自己畫。

## 可以調什麼

全部都是 CSS 變數，寫在 `.foil` 上就會蓋掉預設值。

### 三種材質共用

| 變數 | 預設 | 白話 |
|---|---|---|
| `--power` | `1` | 閃光總強度 |
| `--bright` | `0.62` | 亮度。調太高會過曝糊成一片白 |
| `--contrast` | `1.8` | 對比。越高色帶越硬越銳利 |
| `--sat` | `1.25` | 飽和 |
| `--blend` | `color-dodge` | 疊到底圖的方式。想溫和一點換 `screen` 或 `overlay` |
| `--gloss` | `0.62` | 白色反光強度 |
| `--gloss-size` | `62%` | 白色反光的範圍 |
| `--card-w` | `300px` | 卡片寬度 |
| `--card-ratio` | 依載體 | 長寬比。用 `data-carrier` 就會自動給；想自己蓋就寫這個 |
| `--card-radius` | 依載體 | 圓角 |

傾斜幅度不是 CSS 變數，是寫在 HTML 上：`data-tilt="14"`（單位是度，`0` 就完全不轉）。

### 方閃專屬（`data-foil="grid"`）

| 變數 | 預設 | 白話 |
|---|---|---|
| `--sq` | `25.3px` | 方格大小。調大變粗顆粒貼紙感，調小變細緻 |
| `--fan` | `62deg` | **放射密度**。轉幾度算一段完整光譜 → 越小放射臂越多越細 |
| `--spin` | `200deg` | **放射轉動**。滑動時整組扇形轉多少，調大掃得越兇 |
| `--soften` | `0.58` | **過渡柔順**。壓低這層的對比。**調高 → 顏色被壓成一塊一塊的色塊；調低 → 過渡越滑順** |
| `--laser` | `1.05` | **雷射感**。彩虹濃度，往上拉越像真的繞射，`1` 是原色 |
| `--disc` | `0.40` | **碟面大小**。CD 佔方格的比例。調到 `0.72` 以上會填滿整格 |
| `--metal` | `0.92` | **銀塊強度**。左上／右下那兩塊金屬反光蓋多滿。`0` = 整格都是 CD |
| `--metal-bright` | `0.95` | 銀塊亮度 |
| `--core` | `0.5` | 光碟正中央那個洞的大小。`0` = 沒有洞 |
| `--groove` | `0.3` | 溝紋強度（碟面上的細同心紋）。`0` = 完全沒有同心圓，只剩放射 |
| `--ring` | `3px` | 溝紋間距 |
| `--bevel` | `0.9` | 45 度斜切的明暗對比。調 `0` 就沒有切面 |
| `--seam` | `1px` | 格線粗細。調 `0` 格線消失 |
| `--sweep` | `280deg` | 左右滑動時色相整體掃過的幅度 |

> **色帶再寬，圈太小還是只會亮一小塊。**
> 彩虹的 `.foil__sheen::after` 是一層 `luminosity` 的徑向漸層，它會把游標那一圈以外壓黑。
> 所以「看起來範圍太小」通常不是 `--spread`（色帶寬度）的問題，是 `--reach`（那一圈的半徑）太小。
> 兩個是不同的東西：`--spread` 決定**幾道彩虹**，`--reach` 決定**亮多大一塊**。

### 碎閃專屬（`data-foil="glitter"`）

| 變數 | 預設 | 白話 |
|---|---|---|
| `--dust` | `110px` | **碎片大小**。整組星星的尺度。調大 = 顆粒變大變疏，調小 = 細碎密集 |
| `--scatter` | `1` | **散佈**。四層星圖各自往自己的隨機方向錯開多少。**`0` = 四層都從同一個角落起算**（疊起來會看得出規律的超級格子），`1` = 完全錯開 |
| `--ox1`~`--oy4` | 見 CSS | 每層自己的隨機方向（0~1）。調參台的「重骰位置」按鈕就是在改這八個數字 |
| `--depth` | `1` | **景深錯位**。四層位移差多少。**`0` = 全部貼平沒有深度**，調大立體感越誇張 |
| `--sparkle` | `1.35` | 星星亮度 |
| `--iris` | `340deg` | **幻彩幅度**。一圈光譜轉幾度。調小 = 一個畫面裡出現好幾道彩虹 |
| `--haze` | `0.55` | 疏密起伏。讓碎閃有明暗分佈，不會整片均勻像雜訊 |
| `--soften` | `0.7` | 過渡柔順（同方閃，壓低對比避免色塊） |
| `--sweep` | `180deg` | 左右滑動時色相整體掃過的幅度 |

> **大顆星星看起來「太平行」的解法不是換位置，是把磁磚放大。**
> 主角那層原本一張磁磚只有 3 顆星、磁磚也小（`--dust × 2.10`），
> 所以整片就是同樣 3 顆一直重複，重複週期比卡片還短 → 一眼看得出排列。
> 現在磁磚放大到 `× 3.40`、顆數加到 9 顆（尺寸等比縮小，螢幕上看起來一樣大、密度也一樣），
> 重複週期比卡片還長，就看不出來了。產生時還加了最小間距檢查，避免幾顆擠在一起或排成一直線。
>
> **為什麼要讓每層各自錯開**：四層星圖如果都從同一個角落起算，而且磁磚大小又是簡單倍數關係，
> 疊起來會週期性對齊，出現肉眼看得到的「超級格子」—— 看起來就不像自然散落。
> 所以每層給一組自己的隨機偏移（`--ox/--oy`），`--scatter` 控制錯開的幅度。
>
> **星星一律是正的**，沒有隨機轉角度 —— 轉過的 ✦ 看起來像雜訊，正的才像貼紙上的印刷星。
>
> **位移速度不是照「越近越快」排的**：主角大星刻意只有 `-0.40`，比它後面的近景 `-1.20` 還小。
> 大顆星星跟著滑鼠跑太兇會很吵，微微動就夠了，深度感交給後面三層去做。
>
> **星星是怎麼畫的**：四層都是內嵌 SVG（`data:image/svg+xml,...` 直接寫在 CSS 裡），
> 沒有任何外部圖檔。每張星圖產生時會把靠近邊界的星星在對面補一顆，所以磁磚平鋪是無縫的。
>
> **顏色不是畫在星星上的**：星星本身是黑底白圖，用 `multiply` 把底下那圈
> 「以指標為圓心的光譜」印上去 —— 所以每顆星的顏色取決於它在畫面上的位置，滑鼠一動整片就換色。
> 星星層之間必須用 `lighten` 疊（取各層白點的聯集），用 `multiply` 會整片變黑。

### 經典彩虹專屬（`data-foil="rainbow"`）

| 變數 | 預設 | 白話 |
|---|---|---|
| `--angle` | `118deg` | 彩虹傾斜角 |
| `--reach` | `1.7` | **炫彩範圍**。亮起來的那一圈鋪多遠。**調小 = 只有游標附近那一塊亮**，調大 = 整張卡都在閃 |
| `--spread` | `400%` | 彩虹密度。越小色帶越細越多條（範圍開到 2400%）|
| `--line` | `1.4px` | 掃描線間距 |

## 踩過的六個坑（照時間順序，免得重犯）

**① 同心圓上的黑環 → 看起來像三條色帶**
最早在同心環的頭尾各放一個黑色停點當「光碟中心」，但 `repeating-radial-gradient` 是整段循環的，
那個黑色會在**每一圈**都畫一條硬邊把顏色切斷。
修法：彩虹頭尾同色（0° → 360°）無縫接回，暗的部分拆成獨立不重複的一層。

**② 放射 ≠ 同心圓**
CD 的彩虹是**照角度**變色（`conic`，從圓心散出去的扇形），不是**照距離**變色（`radial`，一圈一圈的同心圓）。
一開始整個做反了。現在主體是 `repeating-conic-gradient`，同心圓只留一點點當表面溝紋（`--groove`）。

**③ 扇形會填滿方格 → 變成四個三角形**
要另外疊一層碟形遮罩（`--disc`）把四角壓暗，才會是「方塊裡有一張圓的 CD」。

**④ 放射被「切塊」，主因不是停點太少，是對比太高**
`contrast()` 開高會把平滑的光譜壓成純色塊（紅綠藍黃各一塊），停點加再多都沒用。
所以這層的對比要另外乘一個 `--soften` 壓下來，同時把色相停點從 12 段加密到 24 段（每 15°）。兩件一起做才順。

**⑤ 想「換材質」只能用遮罩，不能再加一層 background**
`background-image` 的各層之間只能「混色」，不能互相「遮擋」。
所以銀塊住在 `.foil__sheen::before`，戴一張 conic 十字遮罩：
從 12 點順時針，`0~90` 右上、`90~180` 右下、`180~270` 左下、`270~360` 左上，透明的地方就是不蓋、露出底下的 CD。
遮罩的 `mask-size` / `mask-position` 必須跟格線那層同步，十字才會剛好落在格子中心。
（為了空出 `::before`，原本住在那裡的「大範圍色彩分區」搬進了主層的 background 堆疊。）

**⑥ 滑到最左／最右出現一條直線斷層 → 是背景平鋪的接縫**
斜向的漸層一旦 `background-repeat: repeat`，磁磚左右邊界的顏色接不起來。
平常那條縫在畫面外，位移拉大時會被推進視野，變成肉眼看得見的直線。
修法兩件事，**缺一不可**：

1. 那幾層（色彩分區 / 金屬掃光 / 彩虹帶 / 光柱）改成 `no-repeat`
2. `background-position` 的乘數必須 **≤ 1**，位置才鎖在 `0%~100%`。
   超過 1 圖會被推出邊界，`no-repeat` 之後就直接變破洞。
   **想要更大的位移量，是把 `background-size` 加大，不是把乘數加大。**

## 輸出 PNG

面板最下面有「下載 PNG」。輸出的是**目前畫面上這張卡**（閃光停在滑鼠最後停的位置）。

| 選項 | 說明 |
|---|---|
| 輸出尺寸 | 1×／2×／3×，或直接選塔羅 300dpi（寬 827px）、600dpi（寬 1654px）|
| **只輸出閃光層（去背 PNG）** | 不含底圖，透明背景。丟進 Photoshop / Affinity 疊在自己的圖上，**圖層混合模式選「線性加亮」或「濾色」** |
| 保留目前的傾斜角度 | 不勾就輸出正面平放的卡（預設）|

卡片外面的陰影不會入鏡（會被畫布邊界切掉，所以一律關掉再拍）。圓角外面是透明的。

**畫布會自動放大留白**：卡片一傾斜，它的實際外框就比版面大（角會凸出去）。
輸出前會量「傾斜後的真實外框」跟版面差多少，四邊補上那麼多留白，所以角不會被切掉。
沒傾斜時留白是 0，尺寸跟以前一樣。輸出尺寸的預設值（300dpi 等）指的是**卡片本身**的寬度，留白是額外加上去的。

**它是怎麼做到的**：把卡片複製一份，用 `getComputedStyle` 把每個元素「算完的樣式」逐條寫進複製品
（含 `::before` / `::after`），塞進 SVG 的 `foreignObject`，讓瀏覽器自己把那張 SVG 畫成圖，再倒進 canvas 存檔。

- **為什麼不用 canvas 重畫**：`mix-blend-mode` / `background-blend-mode` / `filter` / `mask` 都是瀏覽器排版時才算的。
  用 canvas 重畫等於整套效果再寫第二遍，以後改 CSS 兩邊就會對不上。讓瀏覽器自己畫最不會走鐘。
- **為什麼是逐條複製樣式，而不是把 `holo.css` 整包塞進去**：雙擊開檔（`file://`）時瀏覽器不准 JS 讀外部 CSS 的內容，
  但 `getComputedStyle` 永遠能用 —— 所以改成問每個元素「你最後長怎樣」。

> ⚠️ 輸出功能是在本機 http 環境下實測通過的（640×1098 一般版與去背版都正確）。
> 雙擊 `file://` 開的情況我沒辦法在同一套環境驗，理論上沒問題（沒用到任何被 file:// 擋掉的 API）。
> 萬一按了沒反應，先把輸出尺寸調小；還是不行就在資料夾裡跑個本機伺服器用 http 開。

## JS 能叫的東西

```js
const api = document.querySelector(".foil")._holo;

api.setAlways(true);   // 常亮，不用滑到上面
api.setTilt(20);       // 改傾斜幅度
api.sweep(4);          // 自動繞一圈 4 秒，示範用
```
