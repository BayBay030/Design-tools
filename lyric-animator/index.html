歌詞動畫產生器 — Demo

透明背景滾動 / 淡入淡出歌詞預覽。匯入音檔 + LRC 時間軸（可由 Whisper 產生）或自行輸入文字。

預覽（棋盤格 = 透明區域）

實際匯出時，此預覽區域會以帶 alpha channel 的格式（例如 ProRes 4444 或 WebM VP9）渲染成影片， 可直接拖入剪接軟體疊加在畫面上，不需去背。本 demo 僅做動畫邏輯與樣式預覽，匯出功能尚未實作。

1. 音檔

00:00 / 00:00
字幕偏移 +0.00s
前奏太長 Whisper 把樂器誤當人聲時,聽到第一句快出來就按上面那顆,offset 會自動算好。

2. 歌詞

影片長度 = 句數 × 停留秒數。轉場時間吃「3. 效果」的過渡速度。
編輯區
一行一句。套用時自動偵測格式 — 含時間碼（LRC / SRT）就照時間,純文字就依音檔長度平分。
匯出時會把上方「字幕偏移」一併套上去。
自動對位(Whisper)
編輯區裡的歌詞 + 上方音檔 → Whisper 反推每句時間軸,灌回編輯區並自動套用。對 Suno 生成有時抓不準,不精確時可用「以播放位置校正首句」再拉 offset。
讀檔（LRC / SRT / TXT）
已有歌詞檔的話直接讀,內容會進編輯區並自動套用。
